# AI Business Copilot

An AI-powered business assistant built using:

- React
- FastAPI
- Ollama
- LangChain
- LangGraph
- ChromaDB
- PostgreSQL

## Features

- Chat interface
- Local LLM using Ollama
- Retrieval-Augmented Generation (RAG)
- Conversation memory
- Business document analysis
